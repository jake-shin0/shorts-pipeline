shorts-pipeline

썰주머니 채널의 쇼츠 제작·업로드 도구 / Shorts production and upload tool for the 썰주머니 channel

소개

shorts-pipeline은 개인이 운영하는 YouTube 채널 썰주머니의 쇼츠 영상을 만들고, 완성된 영상을 운영자 본인의 채널에 업로드하는 개인용 도구입니다. YouTube Data API는 운영자 본인 채널에 영상을 업로드하는 용도로만 사용합니다.

About

shorts-pipeline is a personal tool used by the operator of the YouTube channel 썰주머니 to produce Shorts videos and upload them to the operator's own channel. The YouTube Data API is used only to upload videos to the operator's own channel. This tool is not offered to other users.
